# Сайт-резюме Михаила Дулика

Одностраничный сайт-визитка на Angular 22. В проекте есть адаптивная вёрстка, светлая и тёмная темы, а также готовое PDF-резюме.

## Данные и файлы резюме

Данные об опыте и навыках находятся в `src/app/app.ts`, остальные разделы — в `src/app/app.html`.

Исходник аватара хранится в `src/imgs/avatar.png` и не попадает в сборку. В header и блоке профиля используются уменьшенные WebP-версии `src/imgs/avatar-{40,80,120,208,312}.webp` с сохранением прозрачности. Браузер выбирает подходящий размер через `srcset` и `sizes` с учётом ширины изображения и плотности пикселей экрана. В сборку через `angular.json` копируются только WebP-версии. При замене фотографии их нужно заново создать из исходника (качество 82, размеры 40, 80, 120, 208 и 312 px).

Кнопка скачивания PDF использует `public/Mikhail-Dulik-Frontend-Developer-Angular.pdf`. При следующем обновлении резюме нужно также актуализировать содержание сайта и PDF.

## Локальный запуск

```bash
npm install
npm start
```

Сайт откроется по адресу `http://localhost:4200`.

## Production-сборка

```bash
npm run build
```

Готовые статические файлы появятся в каталоге `dist`.

## GitHub Pages

В репозитории уже настроен GitHub Actions workflow. После публикации кода на GitHub:

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **GitHub Actions**.
3. Запустите workflow **Deploy Angular resume to GitHub Pages** или отправьте изменения в ветку `main`.

Приложение использует относительный `base href`, поэтому работает как на корневом домене, так и в подпапке GitHub Pages.
